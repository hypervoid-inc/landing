# Alternate card directions

Approved artwork from the round that chose the homepage card. None of these is
published; they are kept because they are worth reusing, and because the
candidates directory they came from is gitignored and gets cleared.

| File                    | What it is                                                                   |
| ----------------------- | ---------------------------------------------------------------------------- |
| `poster-plate.webp`     | The style lock for the poster direction. Attach it when generating more of these. |
| `poster-b.webp`         | Same direction, alternate composition.                                        |
| `poster-c.webp`         | Same direction, alternate composition.                                        |
| `poster-247-spec.webp`  | The `24/7` display type with the specification block.                         |
| `catalogue-a.webp`      | Cream page, ruled frame, boxed software, `SYSTEM REQUIREMENTS` list.          |
| `catalogue-b.webp`      | The same, with a quick-start card in the still life.                          |
| `keyart.webp`           | Film-poster key art. Features a person, so it is not a drop-in for a route card. |
| `magazine.webp`         | Mascot bursting through shattering glass, chrome wordmark.                    |

The published homepage card came out of this round and lives at
`assets/og/poster/home.webp`. The other 33 routes use the studio system in
`scripts/og/poster.mjs`, which none of these follow: they are one-offs, and
dropping one into the set would break its consistency.

The catalogue and magazine pairs were flagged as worth remixing for other
surfaces rather than for route cards, because they read as beautiful without
explaining what the product does.
