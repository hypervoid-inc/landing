# Logo sources

Brand marks used on printed social cards, where a card names or compares a
product. Each is the brand's own mark, unaltered apart from being resized to
256x256 on a transparent ground. They identify the product being discussed
and imply no endorsement or affiliation.

| Source | Logos |
| ------ | ----- |
| [Simple Icons](https://simpleicons.org) 16.30.0, filled with each entry's brand colour | claude, gemini (googlegemini), google, gmail, google-calendar, telegram, discord, hubspot, linear, zapier, make, n8n, perplexity, cursor, cloudflare, github, notion, hostinger, meta |
| Wikimedia Commons, `Slack_icon_2019.svg` | slack |
| The product's own site icon (apple-touch-icon, or its favicon via Google's favicon service) | openai (openai.com), grok (grok.com), copilot (copilot.microsoft.com), vscode (code.visualstudio.com), composio (composio.dev), exa (exa.ai), lindy (lindy.ai), manus (manus.im), viktor (viktor.com), sintra (sintra.ai), marblism (marblism.com), cellcog (cellcog.ai), genspark (genspark.ai), openclaw (openclaw.ai), hermes (nousresearch.com), simular (simular.ai), runbear (runbear.io), myclaw (myclaw.ai), muse (muse.ai), relay (relay.app), gumloop (gumloop.com), relevance (relevanceai.com), artisan (artisan.co) |

Fetched 2026-10-11. To add one, save a 256x256 PNG here and give it an entry,
with the names it goes by, in `scripts/og/print/logos.mjs`.
