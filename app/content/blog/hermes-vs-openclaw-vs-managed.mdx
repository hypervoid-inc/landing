Construct gives you a managed AI employee from $9 a month with nothing to install, host, or keep awake: its own workspace, files, schedules, and email address, with model usage included in the plan. Hermes Agent and OpenClaw are free, MIT-licensed software, but you supply the machine and pay the model bill yourself; Nous Research hosts Hermes from $20 a month in credits, and OpenClaw has no official hosted version, so it relies on third-party hosts from $5.99 a month. For non-technical founders and small teams, Construct is the better choice: there is no server to maintain or harden, the plan is a fixed monthly price with published limits rather than a bill that moves with token use, the agent's memory is something you can read and correct, and the whole team works from one shared workspace.

If you are technical and want to own every layer, both open-source agents are covered in detail below, with sources. Prices and documentation were checked on October 1, 2026.

## Why choose Construct over running Hermes or OpenClaw?

- **Nothing to run.** Sign up in a browser and assign work. There is no installer, server, bot token, update, or approval setting to manage, and Calendar schedules run on Construct's servers with your laptop closed. OpenClaw's own FAQ tells you to use a VPS if you want 24/7 reliability.
- **A fixed monthly price, models included.** Lite is $9 with base model usage included and published plan limits, with no per-message billing and no separate model provider to pay. On Pro you can still bring keys for OpenRouter, OpenAI, Anthropic, Amazon Bedrock, or xAI.
- **Memory you can read and fix.** Hermes writes skills for itself. Construct shows you what it has learned, and you can correct or forget a fact before the next run relies on it.
- **Work that lands in files.** Reports, spreadsheets, and scripts are saved to workspace files as the agent produces them, so a run that stops at step 30 keeps steps 1 to 29.
- **A team workspace without seats.** On any plan, invite teammates as Owner, Admin, or Member. There is no member limit, and everyone's work draws on the owner's plan.
- **Its own inbox, plus your chat apps.** Each agent has its own email address, and you can reach it from the web, Slack, Telegram, or Discord.

## Hermes Agent: the agent that writes its own skills

Hermes Agent is Nous Research's open-source agent. It creates skills from experience, improves them during use, searches its own past conversations, and builds a model of the user across sessions ([Hermes Agent on GitHub](https://github.com/NousResearch/hermes-agent)). TechCrunch described it as shipping with built-in skills such as web search, coding, and image understanding, and designed to build more skills from people's usage ([TechCrunch](https://techcrunch.com/2026/07/13/hermes-agent-maker-nous-research-in-talks-for-new-funding-at-1-5b-valuation/)). TechCrunch reported about 214,000 GitHub stars in July 2026, when Nous was raising at least $75 million at a $1.5 billion valuation; the repository showed 250,400 when we checked.

**Getting started.** The site offers desktop apps for macOS and Windows and a one-line installer, and the installation guide promises "under two minutes" ([Hermes installation](https://hermes-agent.nousresearch.com/docs/getting-started/installation)). After installing, you run `hermes model` to pick a model, `hermes tools` to enable tools, and `hermes gateway setup` to connect chat apps, or `hermes setup --portal` to use a Nous Portal subscription for all of it. The desktop app needs an Apple Silicon Mac; Intel Macs are not supported.

**Where it runs.** On your computer, in Docker, over SSH, or on serverless backends such as Daytona and Modal ([Hermes docs](https://hermes-agent.nousresearch.com/docs)). Nous Portal adds Agent Cloud Hosting, which runs your agent in the cloud with server costs billed to your credit balance ([Nous Portal](https://portal.nousresearch.com/)). Plans are Free ($0, free models only), Plus ($20 with $22 of credits), Super ($100 with $110), and Ultra ($200 with $220). MyClaw also sells managed Hermes hosting ([MyClaw](https://myclaw.ai/)).

**Safety.** Hermes checks commands before running them. Its default "Smart" mode uses an auxiliary model to assess risk, low-risk commands are auto-approved, and a hardline blocklist refuses things like `rm -rf /` even in YOLO mode, which otherwise bypasses approvals. Unknown people who message the bot get a one-time pairing code you must approve ([Hermes security](https://hermes-agent.nousresearch.com/docs/user-guide/security)). Its security policy states: "The only security boundary against an adversarial LLM is the operating system," and "Within the authorized set, all callers are equally trusted" ([Hermes SECURITY.md](https://github.com/NousResearch/hermes-agent/blob/main/SECURITY.md)).

**What to watch.** If you use Nous Portal, its privacy policy says Nous collects "prompts, instructions, messages, uploads, inputs, outputs" and may use derived data for "artificial intelligence training," unless you turn on Privacy Mode, which applies only from the moment you enable it ([Nous privacy policy](https://portal.nousresearch.com/privacy)). Construct does not train on your data.

## OpenClaw: the foundation-run agent for every chat app

OpenClaw has 391,000 GitHub stars, an independent foundation, and Microsoft's Autopilot agent built on top of it ([OpenClaw on GitHub](https://github.com/openclaw/openclaw), [OpenClaw blog](https://openclaw.ai/blog/microsoft-autopilot-openclaw)). It describes itself as a self-hosted gateway that connects chat apps to AI agents ([OpenClaw docs](https://docs.openclaw.ai/)), and it supports WhatsApp, Telegram, Slack, Discord, Signal, iMessage, Teams, Matrix, SMS, and more.

**Getting started.** Desktop apps for macOS, Windows, and Linux, an installer script, or `npm i -g openclaw` ([OpenClaw](https://openclaw.ai/)). The docs estimate about five minutes for a basic setup with an API key. Keeping it running is the harder part: "Want 24/7 reliability? Use a VPS," the FAQ says, because a laptop gateway pauses when it sleeps ([OpenClaw FAQ](https://docs.openclaw.ai/help/faq-first-run/providers-and-hosting)).

**Where it runs.** Your own machine or a server. There is no official hosting: the Foundation says "No subscription. No hosted tier. No token," and its new OpenClaw Enterprise is also "built to run on your own infrastructure" ([OpenClaw Enterprise](https://openclaw.ai/blog/openclaw-enterprise)). Third parties fill the gap, from Hostinger's 1-Click OpenClaw at $5.99 a month paid upfront to MyClaw at $29 a month. Our guide to [hosted OpenClaw alternatives](/blog/hosted-openclaw-alternatives/) compares them.

**Safety.** The gateway listens only on the local machine by default, and strangers who message the bot get a pairing code. But "Sandboxing and exec approvals are off by default," and "Hardening is deliberate configuration" ([Why OpenClaw](https://docs.openclaw.ai/start/why-openclaw)). When you do turn approvals on, they arrive as buttons in Slack, Telegram, Discord, or Teams.

**What to watch.** The heartbeat. By default OpenClaw wakes every 30 minutes, and "Heartbeats run full agent turns. Shorter intervals burn more tokens." Isolating those runs cuts each one from "~100K tokens down to ~2-5K" ([OpenClaw heartbeat docs](https://docs.openclaw.ai/gateway/heartbeat)).

### How do Hermes and OpenClaw differ underneath?

OpenClaw's documentation includes a source-by-source comparison with Hermes, built around the idea that OpenClaw can separate a trusted gateway from untrusted execution, and it points out that Nous is venture-funded while the OpenClaw Foundation "sells nothing" ([OpenClaw and Hermes Agent](https://docs.openclaw.ai/start/why-openclaw/openclaw-and-hermes-agent)). That page is written by one side, and it says so. Hermes, for its part, leans on its learning loop and its hosted Portal.

For a founder, the practical differences are smaller than the debate suggests. Hermes is quicker to get running and has an official hosted option; OpenClaw reaches more chat apps. Both need someone to decide what the agent can touch, keep it updated, and watch the model bill. A managed AI employee takes that work off your plate.

## Which is best for a non-technical founder?

Look at the work, not the agent. Three questions decide it.

**1. Will anyone keep it running?** Both open-source agents install in minutes. The work comes afterwards: updates, a machine that stays awake, channel bot tokens, approval settings, and a token budget. If nobody on the team will do that, Construct runs it for you, and its Calendar schedules keep going with every laptop closed.

**2. How predictable must the bill be?** The open-source agents' model bill moves with how much the agent does and how often it wakes up. Nous Portal draws models, tools, and hosting from one credit balance. Construct is a fixed monthly price, from $9, with published plan limits and no per-message billing.

**3. Where does the work arrive?** If work arrives by email, in Slack, or as a recurring job, Construct handles it and gives the agent its own inbox, so clients and suppliers can write to it directly. If your customers write on WhatsApp or iMessage, see the narrow cases below.

**An illustrative example.** This is illustrative, not a customer case study. A founder of a two-person design studio wants three things: a Monday summary of new client emails, a weekly check of three suppliers' price lists, and replies drafted for her to approve. On Construct Lite at $9, the three jobs fit the 3 scheduled tasks, the supplier price lists land as dated files in the workspace, client emails can go straight to the agent's own address, and the replies wait as drafts until she sends them. On Hermes via Nous Portal Plus, she pays $20 a month in credits, connects a chat app for the summary, and learns what Smart approval mode will and will not ask about. On OpenClaw, she picks a host, adds a model key, and sets the heartbeat to isolated sessions before the first bill.

## Already running Hermes or OpenClaw? Add Construct in 15 minutes

You do not have to shut your agent down. Move the recurring business job that most needs to run reliably, or the one your teammates need to see.

1. **Start on Lite for $9, or take the 7-day Pro trial** to test your own model keys and longer runs.
2. **Copy the instructions and skill descriptions** that job relies on into a Construct chat, and move its source files into the workspace.
3. **Connect the apps** the job needs from the integration catalog, or add your own MCP tools.
4. **Run it once and check the result** in Files.
5. **Put it on the Calendar** so it runs every week whether or not anyone is online.

There is no import: Hermes skills and OpenClaw memory do not transfer, so write your rules into the first instruction and Construct saves them as memory you can read. Two things to set up deliberately: Construct's workflows do not pause for approval yet, so for anything customer-facing, ask for drafts and send them yourself; and each terminal command is capped at 300 seconds, so keep any long-running service on the machine that runs it today.

## When might Hermes or OpenClaw still fit?

- Your customers and suppliers write on WhatsApp, Signal, iMessage, or Teams, and the agent must answer there.
- You want to run local models or keep the whole stack on your own infrastructure.
- You want to read and change the agent's code.

For recurring business work across a few apps, with a fixed price and nobody on call to maintain an agent, Construct is the better fit. If you are weighing a managed OpenClaw-based product, see [Construct vs Genspark Claw](/blog/construct-vs-genspark-claw/).

Choose Construct. It starts at $9 with base model usage included, has no server or installer for you to maintain, keeps memory you can read and correct, and leaves every finished file in a workspace your team shares. Give Construct your Monday summary first: forward client emails to its address or connect your inbox, ask for a dated file of what needs a reply, check it once, and put it on the Calendar. Start on [Lite at $9](/pricing/), or try Pro free for seven days.
